### Features
- 👥 **Role-Based Access:** System Admin, Mess Manager, and Student profiles
- 📋 **Live Attendance & Daily Menu:** Real-time meal logging
- 💳 **Monthly Billing & Offline Payment Ledger:** Accurate calculated meal dues
- 📦 **Inventory Management:** Low stock and out-of-stock tracking
- 📢 **Circulars & Complaints:** Institutional communication portal
